**https://juliabayes.org**

JuliaBayes is a shared home for Bayesian software in Julia, making it easier to collaborate, share maintenance, and keep packages supported over time.

We welcome collaborators across probabilistic programming languages, research groups, and institutions.
Most of us contribute alongside our day jobs, so contributions of all sizes are welcome.

Interested in joining? Read [how the JuliaBayes community works](https://github.com/JuliaBayes/community/blob/main/README.md).
Have a package you’d like to bring into JuliaBayes? See [how package transfers work](https://github.com/JuliaBayes/community/blob/main/README.md#your-package-stays-yours).
Come say hello in [`#bayes` on Julia Slack](https://julialang.org/slack/) if you’d like to chat!
